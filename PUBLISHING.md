# Publish with GitHub Pages

1. Create a public GitHub repository named `CS-499-ePortfolio`.
2. Upload all contents of this folder.
3. Open **Settings > Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub to provide the site URL.

## Before submission
- Replace all bracketed prompts.
- Add original and enhanced source files.
- Add final Word narratives if required.
- Replace `VIDEO_ID`.
- Test all links.
- Add screenshots.
- Remove credentials and private information.
